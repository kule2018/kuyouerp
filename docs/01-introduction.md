# 01 · 项目简介

## 这是什么

**kuyou-nestjs-vue** 是一个开源的进销存（ERP）管理系统，覆盖企业从「采购 → 入库 → 生产 → 销售 → 财务 → 分析」的完整经营链路。它以 **NestJS（后端）+ Vue 3（前端）** 技术栈重写，目标是提供一套结构清晰、易于扩展、可私有化部署的现代进销存解决方案。

与传统的「一个页面写一个控制器」不同，本项目核心设计是 **引擎化**：把大量形态相似的页面归纳为四种通用引擎（动态 CRUD、单据、报表、专项计算），用配置与元数据驱动前端渲染和后端逻辑，从而用少量核心代码覆盖上百张业务表与几十类业务单据。

---

## 核心特性

### 1. 基础资料（通用 CRUD）
覆盖商品、仓库、客户、供应商、职员、账户、单位、商品分类、收支类别、结算方式、辅助属性、车间、委外工厂、司机、自取地址、轮播、系统配置、用户等。全部业务表由 **动态 CRUD 引擎** 统一提供增删改查、搜索、分页与表单渲染，新增一张表无需手写控制器即可获得完整后台管理能力。

### 2. 业务单据（主从结构 + 审核过账 + 库存联动）
支持购货 / 销货及其订单与退货、零售 / 零售退货、调拨、盘点、序列号盘点、其他出入库、组装拆卸、成本调整、收款付款、资金转账、核销、其他收支、订货单、生产计划 / 生产单 / 领料 / 委外 / 验收等数十类单据。

每张单据都是「表头 + 明细行 + 审核」结构，引擎负责：
- 事务内主从保存（先写主表拿单号，再整体替换明细行，避免孤儿数据）；
- 审核 / 反审核（状态幂等保护）；
- 审核时按方向增减库存、反审核反向冲回；调拨单调出仓减、调入仓加。

### 3. 报表中心
采购 / 销售 / 库存 / 资金四大类报表，支持日期区间、字典筛选、分组汇总、数值合计与 CSV 导出。报表由「报表定义」驱动，用户输入只进入参数化 `WHERE`，杜绝 SQL 注入。

### 4. 计算型专项
- **MRP 计算**：生产计划 → BOM 逐级展开子件 → 毛需求扣库存 → 得建议采购量；
- **智能补货**：区间销量 + 安全库存 − 现有库存 − 在途采购量 = 建议采购量；
- **已销订购看板**：销售订单回填已销 / 已出库 / 关联采购单状态；
- **计件 / 计时工资**：依据 BOM 工序单价与工时计算；
- **结账 / 反结账**：期末商品成本快照（移动平均 / 先进先出双口径）；
- **系统初始化**：事务清空业务表并恢复系统出厂默认值。

### 5. 打印中心
采购 / 销售 / 退换货 / 调拨 / 盘点 / 组装拆卸 / 收付款 / 核销 / 其他收支等 **17 类单据** + 采购明细 / 订单跟踪 / 采购汇总 / 付款流水 / 销售跟踪等 **6 类汇总表**，含人民币大写与打印次数自增。

### 6. 收付款核销与库存盘点
- **收付款核销**：独立收 / 付款单流，在事务内冲减客户应收 / 供应商应付、登记往来明细与账户流水、更新结算账户余额并写操作日志；
- **库存盘点过账**：盘点单建单带入系统库存，盘盈 / 盘亏审核过账并校正库存。

### 7. 数据中心看板
近 7 日购货 / 销货趋势、按仓库库存统计、账户资金统计、本月购销汇总。

### 8. BOM 配方 / 工序
清单 + 工序主从编辑，明细行增删后自动回算清单数量 / 金额合计。

### 9. 开票登记与往来对账
采购 / 销货开票登记 + 台账冲销；客户应收 / 供应商应付对账表。

### 10. AI 能力层（可选）
内置 OpenAI 兼容的对话、Agent 多轮执行、工具调用、知识库检索、模型与提示词管理、调用日志，可帮助企业把自然语言转化为查询与操作。详见 [06 · AI 能力层](./06-ai-layer.md)。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | **NestJS 10** + TypeScript + **TypeORM** + **MySQL 8** + **JWT / Passport** |
| 前端 | **Vue 3** + **Vite** + TypeScript + **Vue Router** + **Axios** + 自建 **DeepSeek UI** 设计系统 |
| AI | OpenAI 兼容 ChatClient + 模型配置库 + Prompt 模板 + `@Tool` 工具调用 + Agent 多轮 + 关键词检索 + 结构化 JSON + 调用日志 |
| 数据库 | MySQL 8（InnoDB，utf8mb4，表名统一 `kuyou_` 前缀，约 156 张业务表） |

> 依赖清单见 `backend/package.json` 与 `frontend/package.json`。除 `openai`、`mysql2`、`xlsx`、`axios` 等必要依赖外，前端**未引入**任何第三方 UI 组件库——全部界面由项目自带的 DeepSeek UI 设计系统承载。

---

## 适用场景

- 想学习 **NestJS + Vue 3** 中大型后台工程化组织方式的开发者；
- 需要一套**可私有化部署、可二开**的进销存底座的中小企业；
- 希望把 **AI 能力**接入企业经营管理系统的团队；
- 作为「配置驱动 / 元数据驱动」架构的教学样例。
